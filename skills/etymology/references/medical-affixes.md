# High-yield medical word parts — standard Arabic equivalents

Use this to keep Arabic renderings consistent across answers. The equivalents follow common usage in Arabic medical terminology (the *Unified Medical Dictionary* / المعجم الطبي الموحد tradition). Two cautions:

- **A whole term's established translation beats the affix pattern.** *Anemia* is فقر الدم, *diarrhea* is إسهال, *polyuria* is بُوال. Build an Arabic term from the parts only when no established one exists, and say that it is a descriptive rendering.
- **This list does not cover everything.** For a part that is not here, or a meaning you are unsure of, verify before you rely on it (see "Accuracy and verification" in SKILL.md).

## 3. Suffixes — procedures and tests

The first three are the most confused trio in surgery — keep their Arabic equivalents fixed.

| Suffix | Origin | Meaning | العربية | Example |
| --- | --- | --- | --- | --- |
| -otomy | Greek *tomē* "cutting" | cutting into, incision | بَضْع | laparotomy بضع البطن |
| -ectomy | Greek *ek* + *tomē* "cutting out" | removal | استئصال | appendectomy استئصال الزائدة |
| -ostomy | Greek *stoma* "mouth" | creating an opening | فَغْر | colostomy فغر القولون |
| -plasty | Greek *plassein* "to mould" | surgical repair, reshaping | رَأْب | rhinoplasty رأب الأنف |
| -rrhaphy | Greek *rhaphē* "seam" | suturing | رَفْو / خياطة | herniorrhaphy رفو الفتق |
| -pexy | Greek *pēxis* "fixing" | surgical fixation | تثبيت | orchiopexy تثبيت الخصية |
| -centesis | Greek *kentēsis* "puncture" | puncture to remove fluid | بَزْل | paracentesis بزل البطن |
| -tripsy | Greek *tripsis* "rubbing" | crushing | تفتيت | lithotripsy تفتيت الحصيات |
| -scopy | Greek *skopein* "to look" | visual examination | تنظير | colonoscopy تنظير القولون |
| -graphy / -gram | Greek *graphein* "to write" | recording / the record | تصوير / مُخَطَّط، صورة | electrocardiogram مخطط كهربية القلب |

## 4. Roots with Greek/Latin pairs

Medicine often keeps a Greek root for diseases and procedures and a Latin root for anatomy and adjectives. Pointing out the pair helps learners see that *nephritis* and *renal* are about the same organ.

| Organ | Greek root | Latin root | العربية |
| --- | --- | --- | --- |
| kidney | nephr- (nephritis) | ren- (renal) | كُلْية |
| liver | hepat- (hepatitis) | — (Latin *iecur* is rarely used) | كَبِد |
| lung | pneumon- (pneumonia) | pulmon- (pulmonary) | رئة |
| skin | derm-, dermat- (dermatitis) | cut- (cutaneous) | جِلْد |
| vessel | angi- (angiography) | vas-, vascul- (vascular) | وعاء |
| vein | phleb- (phlebitis) | ven- (venous) | وريد |
| uterus | hyster- (hysterectomy) | uter- (uterine) | رَحِم |
| breast | mast- (mastectomy) | mamm- (mammary) | ثَدْي |
| eye | ophthalm- (ophthalmology) | ocul- (ocular) | عين |
| ear | ot- (otitis) | aur- (aural) | أُذُن |
| nose | rhin- (rhinitis) | nas- (nasal) | أنف |
| mouth | stomat- (stomatitis) | or- (oral) | فم |
| stomach / belly | gastr- (gastritis) | ventr- (ventral) | معدة / بطن |
| tongue | gloss- (glossitis) | lingu- (lingual) | لسان |
| blood | hem-, hemat- (hematoma) | sanguin- (sanguineous) | دم |
| bone | oste- (osteoporosis) | oss- (osseous) | عَظْم |
| nerve | neur- (neuritis) | nerv- (nervous) | عَصَب |

Other frequent roots: cardi- قلب، enter- أمعاء، col- قولون، arthr- مفصل، my- عضلة، myel- نخاع (عظمي أو شوكي)، encephal- دماغ (literally "what is in the head")، cephal- رأس، cyst- مثانة / كيس، chole- صفراء، cyt- خلية، thromb- خُثرة، lith- حصاة، lip- شحم، glyc- سكر، carcin- سرطان، hist- نسيج.

## 5. Commonly confused parts

Mention one of these as the "Important distinction" when it applies.

| Pair | The difference |
| --- | --- |
| -otomy / -ectomy / -ostomy | cut into (بضع) / cut out (استئصال) / make an opening (فغر) |
| hyper- / hypo- | over (فرط) / under (نقص، قصور) |
| -plasia / -trophy | change in cell number / change in cell size |
| -penia / -cytosis | too few cells / too many cells |
| -rrhea / -rrhage | flow or discharge / profuse bleeding |
| -phagia / -phasia | swallowing / speech |
| my- / myel- | muscle / marrow or spinal cord |
| arthr- / arter- | joint / artery |
| ileum / ilium | part of the small intestine (اللفائفي) / hip bone (الحرقفة) |
| peri- / para- | around / beside |
| dys- (Greek) / dis- (Latin) | bad or difficult / apart, reversal |
| -oma | "mass", not always a neoplasm: hematoma, granuloma |
